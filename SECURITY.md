# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability or state persistence integrity issue in Anchor, please do not open a public issue.

Instead, please report security vulnerabilities directly via email to:
- **Jason Song**: `jiaxinsong312@gmail.com`

Please include:
1. Steps to reproduce the vulnerability;
2. Operating system and Node.js version;
3. Proof-of-concept exploit or script if available.

We will acknowledge receipt within 48 hours and work on a fix promptly.
